# Tyler Ren · Robot Learning Notes

Personal academic website and research blog for robot learning, embodied AI, vision-language-action models, imitation learning, and Sim-to-Real.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000/`.

## Deployment

Pushes to `main` are built and deployed to GitHub Pages by `.github/workflows/pages.yml`.

## Theme

Built with the MIT-licensed [H2O-ac Jekyll theme](https://github.com/zhonger/jekyll-theme-H2O-ac), with custom content, navigation, imagery, and deployment configuration.
